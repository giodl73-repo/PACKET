# Rust 1.95.0 library copyright notices

`COPYRIGHT-library.html` and `licenses/` are the unmodified library notice
documents supplied by the pinned Rust 1.95.0 distribution. They include notices
for other platforms as well as common library code. They are attribution/legal
documents, not additional application/runtime implementations.

Their original licenses remain in force; PACKET's first-party MIT grant does not
relicense these documents or the third-party code they describe. The builder
also collects notices from the portable adapter's exact Cargo dependency closure.
Scoped Git attributes preserve the upstream bytes and suppress whitespace-error
checks only for these verbatim legal files. Authored code/docs retain normal checks.
